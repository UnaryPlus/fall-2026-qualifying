# fall-2026-qualifying

Lean proof of a UMass Amherst fall 2026 algebra qualifying exam problem. See problem 7 in Exam.pdf for the original problem, and Fall2026Qualifying/Basic.lean for the proof.

I wrote most of the proof myself (including all of the lemma statements), but some sections were generated by Claude Code Opus 5.5. These sections are delineated by comments and in total make up 25%&ndash;30% of the Lean file.
